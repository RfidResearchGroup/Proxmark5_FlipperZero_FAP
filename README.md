# Proxmark5 for Flipper Zero

## Menus

- **HF 14a Reader** and **Hitag2 Reader** show the selected tag's UID.
- **Hardware Status** shows PM5 link diagnostics, BWM battery details,
  Wi-Fi state and IPv4 address, and BLE state, name, pairing and bonded
  device count. Press OK to refresh.
- **Hardware → BWM Power Settings** changes BWM power save and Wi-Fi sleep. Press OK to edit, Left/Right to choose and OK to apply. Back before Apply discards the edit.
